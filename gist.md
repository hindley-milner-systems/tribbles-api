It wraps a value, allowing you to operate on it with monadic functions. ### Properties - `map` - Applies a function to the wrapped value - `chain` - Applies a function that returns a monad - `extract` - Extracts the value from the monad - `concat` - Combines two Id values using their underlying value's concat method ### Examples ```javascript import { Id } from "./monads"; // Create an Id from a value const id = Id(5); // Map a function over the value const doubled = id.map((x) => x * 2); // Id(10) // Chain with a function that returns an Id const squared = id.chain((x) => Id(x * x)); // Id(25) // Extract the value const value = squared.extract(); // 25 // Use Id.of as an alternative constructor const idString = Id.of("hello"); const upperCased = idString.map((s) => s.toUpperCase()); // Id("HELLO") // Concatenate Ids const id1 = Id.of([1, 2]); const id2 = Id.of([3, 4]); const combined = id1.concat(id2); // Id([1, 2, 3, 4]) ``` ## IdT (Identity Transformer) `IdT` is a monad transformer for the `Id` monad. It allows you to combine the `Id` monad with another monad `M` to create a composite monad. ### Properties - `map` - Applies a function to the wrapped value - `chain` - Applies a function that returns a monad - `extract` - Extracts the underlying monad - `of` and `lift` static methods for construction ### Examples ```javascript import { IdT, Either } from "./monads"; // Create an IdT transformer with the Either monad const IdEither = IdT(Either); // Create a value using of const value = IdEither.of(42); // Id(Either.Right(42)) // Lift an existing Either into the transformer const eitherVal = Either.Right("success"); const lifted = IdEither.lift(eitherVal); // Id(Either.Right("success")) // Map over the value const mapped = value.map((x) => x + 10); // Id(Either.Right(52)) // Chain with a function that returns an IdEither const chained = value.chain((x) => IdEither.of(x % 2 === 0 ? "even" : "odd")); // Id(Either.Right("even")) // Extract the underlying Either const either = chained.extract(); // Either.Right("even") ``` ## IO `IO` represents computations that might perform I/O operations. It's lazy and only executes when explicitly run. ### Properties - `run` - Executes the IO operation - `map` - Transforms the result of the IO - `chain` - Sequences IO operations - `concat` - Combines two IO instances ### Examples ```javascript import { IO } from "./monads"; // Create an IO that gets the current time const getTime = IO(() => new Date().toISOString()); // Create an IO that logs to the console (simulated) const log = (message) => IO(() => { console.log(message); return message; }); // Map over the result of getTime const formattedTime = getTime.map((time) => `Current time: ${time}`); // Chain IOs together const logCurrentTime = getTime.chain((time) => log(`The time is ${time}`)); // Execute the IO to perform the action const message = logCurrentTime.run(); // Logs and returns the message // Use IO.of for a constant value const constant = IO.of(42); const constantValue = constant.run(); // 42 // Combine IOs with concat const getName = IO(() => "John"); const getAge = IO(() => 30); // Assuming the returned values have a concat method const getInfo = getName.concat(getAge); ``` ## Fn (Function) `Fn` wraps a function to create a monad that represents a computation requiring some input. ### Properties - `run` - The wrapped function - `map` - Composes a function with the result of the wrapped function - `chain` - Sequences functions that return Fn instances - `concat` - Combines two Fn instances - `Fn.ask` - The identity function wrapped in Fn - `Fn.of` - Creates a Fn that ignores its input and returns a constant ### Examples ```javascript import { Fn } from "./monads"; // Create a function that doubles its input const double = Fn((x) => x * 2); // Apply the function to a value const result = double.run(5); // 10 // Compose functions with map const addFive = double.map((x) => x + 5); const result2 = addFive.run(5); // 10 + 5 = 15 // Use chain for sequence const multiply = (x) => Fn((y) => x * y); const addThenMultiply = Fn((x) => x + 1).chain(multiply); const result3 = addThenMultiply.run(3); // (3 + 1) * (3 + 1) = 16 // Using Fn.ask to get the current environment const getInput = Fn.ask; const result4 = getInput.run(42); // 42 // Using Fn.of to create a constant function const constant = Fn.of(100); const result5 = constant.run("any input"); // 100 ``` ## FnT (Function Transformer) `FnT` is a monad transformer for the `Fn` monad, allowing you to combine the function monad with another monad. ### Properties - Same as `Fn`, but operates on the combined monad structure - `lift` - Lifts a monad instance into the transformer ### Examples ```javascript import { FnT, Either } from "./monads"; // Create a function transformer with the Either monad const FnEither = FnT(Either); // Create a function that returns a Right if even, Left if odd const isEven = FnEither((x) => x % 2 === 0 ? Either.Right(`${x} is even`) : Either.Left(`${x} is odd`) ); // Run the function with an input const result1 = isEven.run(4); // Either.Right("4 is even") const result2 = isEven.run(3); // Either.Left("3 is odd") // Map over the result const emphasize = isEven.map((str) => str.toUpperCase()); const result3 = emphasize.run(4); // Either.Right("4 IS EVEN") // Use FnEither.ask to get the input const getInput = FnEither.ask; const result4 = getInput.run(42); // Either.of(42) // Use FnEither.of for constant values const constant = FnEither.of("hello"); const result5 = constant.run("ignored"); // Either.of("hello") // Lift an existing Either const eitherVal = Either.Right("success"); const lifted = FnEither.lift(eitherVal); const result6 = lifted.run("ignored"); // Either.Right("success") ``` ## Either `Either` represents a value that can be one of two types: `Left` or `Right`. It's commonly used for error handling, where `Right` represents success and `Left` represents an error. ### Properties - `isLeft` - Boolean indicating if the value is Left - `chain`, `map`, `ap` - Standard monadic operations (only applied if Right) - `alt` - Returns the alternative if Left - `extend` - Applies a function to the entire Either - `concat` - Combines two Either values - `traverse` - Transforms the Right value with a function that returns an Applicative - `fold` - Applies one of two functions depending on whether it's Left or Right - `toString` - Returns a string representation ### Examples ```javascript import { Either } from "./monads"; // Create Either values const right = Either.Right(5); const left = Either.Left("error"); // Check if it's Left console.log(right.isLeft); // false console.log(left.isLeft); // true // Map only transforms Right values const rightMapped = right.map((x) => x * 2); // Right(10) const leftMapped = left.map((x) => x * 2); // Still Left("error") // Chain const rightChained = right.chain((x) => Either.Right(x + 1)); // Right(6) const leftChained = left.chain((x) => Either.Right(x + 1)); // Still Left("error") // Fold to handle both cases const rightFolded = right.fold( (err) => `Error: ${err}`, (val) => `Value: ${val}` ); // "Value: 5" const leftFolded = left.fold( (err) => `Error: ${err}`, (val) => `Value: ${val}` ); // "Error: error" // Create from nullable values const maybeNull = null; const eitherFromNull = Either.fromNullable(maybeNull); // Left(null) const notNull = "hello"; const eitherFromNonNull = Either.fromNullable(notNull); // Right("hello") // tryCatch for exception handling const safeOperation = Either.tryCatch(() => { return 10 / 0; // This would normally throw }); // This will be Left(Error) const safeAdd = Either.tryCatch(() => { return 5 + 5; }); // Right(10) // Alt for providing a fallback const withFallback = left.alt(Either.Right("fallback")); // Right("fallback") ``` ## EitherT (Either Transformer) `EitherT` is a monad transformer for `Either`, allowing you to combine the error-handling of `Either` with another monad. ### Properties - Similar to `Either` but works with the underlying monad - `extract` - Extracts the underlying monad ### Examples ```javascript import { EitherT, Id } from "./monads"; // Create an Either transformer with the Id monad const EitherId = EitherT(Id); // Create a Right value const right = EitherId.of(5); // EitherId.Right(Id(5)) // Create a Left value const left = EitherId.Left(Id("error")); // EitherId.Left(Id("error")) // Map over a Right value const rightMapped = right.map((x) => x * 2); // EitherId.Right(Id(10)) // Chain with a function returning an EitherId const rightChained = right.chain((x) => x > 0 ? EitherId.of(x + 1) : EitherId.Left(Id("not positive")) ); // EitherId.Right(Id(6)) // Fold to handle both cases const rightValue = right.fold( (errM) => errM.map((err) => `Error: ${err}`), (valM) => valM.map((val) => `Value: ${val}`) ); // Id("Value: 5") // Extract the underlying monad const idValue = right.extract(); // Id(5) // Try/catch with EitherId const tryCatchResult = EitherId.tryCatch(() => 10 / 2); // EitherId.Right(Id(5)) ``` ## Task `Task` represents an asynchronous computation that might fail. It's similar to a Promise but is lazy (it doesn't execute until forked). ### Properties - `fork` - Executes the Task with success and failure callbacks - `map` - Transforms the success value - `chain` - Sequences asynchronous operations - `ap` - Applies a Task of a function to a Task of a value - `concat` - Combines two Tasks - `fold` - Transforms both success and failure values ### Examples ```javascript import { Task } from "./monads"; // Create a Task that resolves after a delay const delay = (ms) => Task((reject, resolve) => { setTimeout(() => resolve(`Completed after ${ms}ms`), ms); }); // Create a Task that might fail const divide = (a, b) => b === 0 ? Task.rejected("Division by zero") : Task.of(a / b); // Map over a Task const delayThenDouble = delay(1000).map((message) => { return `${message} and the result is doubled`; }); // Chain Tasks together const delayThenDivide = delay(1000).chain((message) => { return divide(10, 2).map((result) => `${message}, result: ${result}`); }); // Execute the Task delayThenDivide.fork( (error) => console.error("Error:", error), (success) => console.log("Success:", success) ); // Convert a Promise-returning function to a Task const fetchData = Task.fromPromised((url) => fetch(url).then((r) => r.json())); // Fetch data from an API const getUserTask = fetchData("https://api.example.com/users/1"); getUserTask.fork( (error) => console.error("API Error:", error), (data) => console.log("User data:", data) ); // Use fold to handle both success and error paths const processResult = divide(10, 0).fold( (error) => Task.of(`Error handled: ${error}`), (result) => Task.of(`Result: ${result}`) ); processResult.fork( (e) => console.error(e), // This shouldn't happen (s) => console.log(s) // "Error handled: Division by zero" ); ``` ## State `State` represents computations that maintain and manipulate state. It's a function from a state to a tuple of [value, newState]. ### Properties - `run` - Executes the State with an initial state - `map` - Transforms the value without affecting the state - `chain` - Sequences state transformations - `concat` - Combines two States - Static methods: `of`, `get`, `modify`, `put` ### Examples ```javascript import { State } from "./monads"; // Simple counter const increment = State((state) => [state, state + 1]); const getState = State.get; // Run the state const [initialState, nextState] = increment.run(0); // [0, 1] // Chain multiple state operations const incrementTwice = increment.chain((_) => increment); const [_, stateAfterTwoIncrements] = incrementTwice.run(0); // [null, 2] // Use State.get to access current state const getAndIncrement = getState.chain((currentState) => increment.map((_) => `State was: ${currentState}`) ); const [message, finalState] = getAndIncrement.run(5); // ["State was: 5", 6] // Use State.put to replace the state const resetState = State.put(0); const [__, resetResult] = resetState.run(100); // [null, 0] // Use State.modify to apply a function to the state const double = State.modify((x) => x * 2); const [___, doubledState] = double.run(3); // [null, 6] // A more complex example: stack operations const push = (x) => State((stack) => [null, [x, ...stack]]); const pop = State((stack) => [stack[0], stack.slice(1)]); const stackOps = push(1) .chain((_) => push(2)) .chain((_) => push(3)) .chain((_) => pop) .chain((top) => State.of(`Popped ${top}`)); const [popMessage, finalStack] = stackOps.run([]); // ["Popped 3", [2, 1]] ``` ## StateT (State Transformer) `StateT` is a monad transformer for the `State` monad, allowing you to combine state management with another monad. ### Properties - Similar to `State` but works with the underlying monad - Static methods: `of`, `get`, `modify`, `put`, `lift` ### Examples ```javascript import { StateT, Either } from "./monads"; // Run the state const result = incrementTwice.run(0); // Either.Right([null, 2]) // Use StateEither.get to access current state const getState = StateEither.get; const getAndIncrement = getState.chain((currentState) => increment.map((_) => `State was: ${currentState}`) ); // Either.Right([null, 0]) // Use StateEither.modify to transform the state const double = StateEither.modify((x) => x * 2); const doubledState = double.run(3); // Either.Right([null, 6]) // Lift an Either into StateEither const eitherVal = Either.of("value"); const liftedEither = StateEither.lift(eitherVal); const liftedResult = liftedEither.run("any state"); // Either.Right(["value", "any state"]) ``` ## Combining Types Algebraic data types become even more powerful when used together. As noted in the code: "Semigroup + Contract = Monoid". A **monoid** is an algebraic structure with two key components: 1. A binary operation that is associative (the Semigroup part) 2. A neutral element or "identity" (the Contract part) In practical terms, monoids follow these laws: - **Associativity**: `(a ⊕ b) ⊕ c = a ⊕ (b ⊕ c)` where ⊕ is the `concat` operation - **Identity Element**: `a ⊕ empty = empty ⊕ a = a` Monoids are incredibly useful for combining values in a consistent, predictable way, which makes them perfect for many common operations in programming like summing numbers, joining strings, or combining data structures. ## Sum `Sum` is a monoid for addition of numbers. ### Properties - `x` - The wrapped value - `concat` - Adds the wrapped values - `empty` - Returns the identity element for addition (0) ### Examples ```javascript import { Sum } from "./monoids"; // Create Sum instances const a = Sum(5); const b = Sum(10); const c = Sum(15); // Combine them using concat const result1 = a.concat(b); // Sum(15) const value1 = result1.x; // 15 // Associativity: (a ⊕ b) ⊕ c = a ⊕ (b ⊕ c) const ab_c = a.concat(b).concat(c).x; // 30 const a_bc = a.concat(b.concat(c)).x; // 30 console.log(ab_c === a_bc); // true // Identity element const empty = Sum.empty(); // Sum(0) console.log(a.concat(empty).x === a.x); // true console.log(empty.concat(a).x === a.x); // true // Practical example: Sum a list of numbers const numbers = [1, 2, 3, 4, 5]; const summed = numbers.reduce((acc, n) => acc.concat(Sum(n)), Sum.empty()); // Sum(15) ``` ## Product `Product` is a monoid for multiplication of numbers. ### Properties - `x` - The wrapped value - `concat` - Multiplies the wrapped values - `empty` - Returns the identity element for multiplication (1) ### Examples ```javascript import { Product } from "./monoids"; // Create Product instances const a = Product(2); const b = Product(3); const c = Product(4); // Combine them using concat const result = a.concat(b).concat(c); // Product(24) const value = result.x; // 24 // Associativity const ab_c = a.concat(b).concat(c).x; // 24 const a_bc = a.concat(b.concat(c)).x; // 24 console.log(ab_c === a_bc); // true // Identity element const empty = Product.empty(); // Product(1) console.log(a.concat(empty).x === a.x); // true console.log(empty.concat(a).x === a.x); // true // Practical example: Calculate factorial function factorial(n) { return Array(n) .fill(0) .map((_, i) => i + 1) .reduce((acc, i) => acc.concat(Product(i)), Product.empty()).x; } console.log(factorial(5)); // 120 (5!) ``` ## Any `Any` is a monoid for logical OR operations. ### Properties - `x` - The wrapped boolean value - `concat` - Performs logical OR on the wrapped values - `empty` - Returns the identity element for OR (false) ### Examples ```javascript import { Any } from "./monoids"; // Any(false) console.log(a.concat(empty).x === a.x); // true console.log(empty.concat(a).x === a.x); // true // Practical example: Check if any value in an array meets a condition function anyGreaterThan10(numbers) { return numbers .map((n) => Any(n > 10)) .reduce((acc, any) => acc.concat(any), Any.empty()).x; } console.log(anyGreaterThan10([5, 8, 12, 3])); // true console.log(anyGreaterThan10([1, 2, 3, 4])); // false ``` ## All `All` is a monoid for logical AND operations. ### Properties - `x` - The wrapped boolean value - `concat` - Performs logical AND on the wrapped values - `empty` - Returns the identity element for AND (true) ### Examples ```javascript import { All } from "./monoids"; Here are some examples of combining monoids: ### Collecting Statistics You can combine multiple monoids to collect various statistics in a single pass through data: ```javascript import { Sum, Product, Max, Min } from "./monoids"; // Including our additional monoids // A monoid for collecting statistics const Stats = (sum, count, min, max) => ({ sum, count, min, max, avg: count > 0 ? sum / count : 0, concat: (other) => Stats( sum + other.sum, count + other.count, Math.min(min, other.min), Math.max(max, other.max) ), }); Stats.empty = () => Stats(0, 0, Infinity, -Infinity); Stats.of = (x) => Stats(x, 1, x, x); // Example usage const data = [2, 5, 9, 1, 7, 3]; const stats = data .map(Stats.of) .reduce((acc, s) => acc.concat(s), Stats.empty()); console.log(stats); // { // sum: 27, // count: 6, // min: 1, // max: 9, // avg: 4.5 // } ``` ### Form Validation Monoids can be used for form validation by collecting all validation errors: ```javascript import { All } from "./monoids"; // A validation monoid that collects errors const Validation = (isValid, errors) => ({ isValid, errors, concat: (other) => Validation( isValid && other.isValid, [...errors, ...other.errors].filter((e) => e) // Filter out null errors ), }); Validation.of = (isValid, error = null) => Validation(isValid, isValid ? [] : [error]); Validation.empty = () => Validation(true, []); // Example usage function validateForm(form) { const validations = [ // Name must be at least 2 characters Validation.of(form.name.length >= 2, "Name is too short"), // Email must contain @ Validation.of(form.email.includes("@"), "Invalid email format"), // Password must be at least 8 characters Validation.of(form.password.length >= 8, "Password is too short"), // Password must contain a digit Validation.of(/\d/.test(form.password), "Password must contain a digit"), ]; console.log(result.isValid); // false console.log(result.errors); // ["Name is too short", "Invalid email format", "Password is too short", "Password must contain a digit"] ``` ### Configuration Merging Monoids can help with merging configuration from multiple sources, where later sources override earlier ones: ```javascript // A monoid for merging nested objects const MergeConfig = (config) => ({ config, concat: (other) => MergeConfig(mergeDeep(config, other.config)), }); MergeConfig.empty = () => MergeConfig({}); // Deep merge helper function mergeDeep(target, source) { const result = { ...target }; for (const key in source) { if ( source[key] && typeof source[key] === "object" && !Array.isArray(source[key]) ) { result[key] = mergeDeep(result[key] || {}, source[key]); } else if (source[key] !== undefined) { result[key] = source[key]; } } return result; } // Example usage const defaultConfig = MergeConfig({ theme: { primary: "blue", secondary: "green", fontSize: 16, }, api: { url: "https://api.example.com", timeout: 5000, }, }); The key benefit is that they allow you to break complex operations into smaller, composable parts that follow a consistent set of laws.
